# Tianji Calendar

Offline-first China market trading calendar for Python.

Tianji Calendar is part of the [Tianji](https://github.com/Angryshark128/tianji)
open-source market research toolkit. It works without network access at runtime
and provides simple APIs for trading-day queries.

## Features

- Offline-first: no network required at runtime
- Market-aware trading calendar model (`CN_A_SHARE`, `SSE`, `SZSE`, `BSE`)
- Built-in China A-share trading calendar (2000–2035)
- Trading-day, previous, next, and range queries
- Simple Python API and CLI
- Explicit import and update workflow (data versioned separately from code)
- No Tushare token required

## Install

```bash
pip install tj-calendar
```

## Quickstart

```python
from tj_calendar import is_trade_day, next_trade_day, trade_days_between

is_trade_day("2026-08-04")
# True

is_trade_day("2025-10-01")  # National Day
# False

next_trade_day("2025-09-30")
# datetime.date(2025, 10, 9)

trade_days_between("2026-08-03", "2026-08-07")
# [datetime.date(2026, 8, 3), datetime.date(2026, 8, 4),
#  datetime.date(2026, 8, 5), datetime.date(2026, 8, 6),
#  datetime.date(2026, 8, 7)]
```

### Market-aware queries

```python
from tj_calendar import is_trade_day

is_trade_day("2021-11-15", market="BSE")  # BSE first trading day
# True

is_trade_day("2018-01-02", market="BSE")  # before BSE existed
# raises tj_calendar.CalendarRangeError:
#   2018-01-02 is outside BSE calendar range 2021-11-15 to 2035-12-31.
```

Each market has its own coverage range. Dates outside a market's range raise
`CalendarRangeError` instead of guessing.

### CLI

```bash
tjcal check 2026-08-04
# 2026-08-04 is a trading day.

tjcal next 2025-09-30
# 2025-10-09

tjcal range 2026-08-03 2026-08-07
# 2026-08-03
# 2026-08-04
# 2026-08-05
# 2026-08-06
# 2026-08-07

tjcal info
# market: CN_A_SHARE
# coverage_start: 2000-01-01
# coverage_end: 2035-12-31
# trade_day_count: 9226

tjcal check 2025-10-01 --json
# {"date": "2025-10-01", "is_trade_day": false, "market": "CN_A_SHARE"}
```

## Date inputs and outputs

Query APIs accept an ISO date string (`"2026-08-04"`), a `datetime.date`, or a
`YYYYMMDD` integer (`20260804`). They return `datetime.date`.

## CLI reference

```text
tjcal today [--market M] [--json]
tjcal check <date> [--market M] [--json]
tjcal next <date> [--market M] [--json]
tjcal prev <date> [--market M] [--json]
tjcal range <start> <end> [--market M] [--json]
tjcal info [--market M] [--json]
tjcal check-update [--json]
tjcal update [--json]
```

## Updating data

The built-in calendar covers through 2035 and all query APIs are fully offline.
After holiday schedules for a new year are announced, update the data explicitly:

```bash
# Configure the update source (metadata URL; required). Use colons to list mirrors.
export TIANJI_CALENDAR_METADATA_URL="https://tj-1310342032.cos.ap-beijing.myqcloud.com/calendar/latest/metadata.json"

tjcal check-update   # fetches only the tiny metadata file to check for updates
tjcal update         # skips when versions match; downloads the bundle (sha256-verified) otherwise
```

Keep data fresh before querying in Python:

```python
from tj_calendar import ensure_fresh, is_trade_day

ensure_fresh()       # silently skips when already current; fetches only metadata
is_trade_day("2026-08-04")
```

`update` verifies the downloaded content via sha256 and preserves the existing
calendar on failure — it never destroys a currently usable dataset.

## Data

- Coverage: `CN_A_SHARE` / `SSE` / `SZSE` from 2000-01-01 to 2035-12-31; `BSE`
  from its first trading day 2021-11-15.
- Built-in data encodes known A-share holiday closures (2019–2027); earlier and
  later years use a weekday approximation and are marked best-effort.
- Queries never hit the network. Updating the calendar is an explicit action.

## Tianji Ecosystem

Tianji is a composable open-source toolkit for market research.
Each package can be used independently or combined into a full workflow.

- tj-calendar: Offline-first trading calendar
- tj-symbols: Symbol normalization and format conversion
- tj-data: Market data adapters and local cache
- tj-factors: Technical indicators and factors
- tj-metrics: Performance metrics
- tj-backtest: Lightweight backtesting
- tj-research: AI-assisted research
- tj-terminal: Integrated research workspace
